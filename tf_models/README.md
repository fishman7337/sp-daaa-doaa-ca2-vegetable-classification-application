# TensorFlow SavedModels

This folder contains exported TensorFlow SavedModel artifacts for VegNet-style serving.

## Structure

- `vegnet-23/`: SavedModel for 23x23 input.
- `vegnet-101/`: SavedModel for 101x101 input.

SavedModel version folders and variable files are generated artifacts. They are documented here and excluded from the folder README gate below the version level.
