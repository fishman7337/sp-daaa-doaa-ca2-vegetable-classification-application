# JavaScript

Browser-side JavaScript modules for the Jinja frontend.

## Modules

- `api.js`: fetch helpers and response handling.
- `auth.js`: login, signup, captcha, and OTP interactions.
- `predict.js`: prediction, camera detection, and upload UI.
- `prices.js`: vegetable price lookup.
- `profile.js`: profile and account settings.
- `site.js`: shared shell behavior.
- `theme-boot.js`: early theme setup.
