# VeggieAI MLOps Platform Submission

This submission package contains the source code, slides, and declaration for the Singapore Polytechnic ST1516 CA2 project by Goh Kun Ming.

## Package Layout

- `Source-Codes/`: main VeggieAI MLOps application, tests, CI/CD configuration, and documentation.
- `Slides/`: presentation deck and exported PDF.
- `Declaration/`: academic declaration document.

Start with `Source-Codes/README.md` for setup, testing, MLOps, and deployment instructions.

GitHub automation is included at both levels:

- `.github/`: works when the entire submission package is the GitHub repository.
- `Source-Codes/.github/`: works when only `Source-Codes/` is published as the GitHub repository.
