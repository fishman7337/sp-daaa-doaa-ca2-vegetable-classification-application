# Templates

Jinja templates rendered by the backend Flask app.

## Pages

- `base.html`: shared shell.
- `home.html`: public landing/home page.
- `auth.html`: login and signup page.
- `predict.html`: authenticated prediction page.
- `prices.html`: authenticated price lookup page.
- `profile.html`: authenticated profile page.

`history.html` and `login.html` are compatibility placeholders; active routes use the templates above.
