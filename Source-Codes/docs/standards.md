# Standards

## Formatting
- Use `.editorconfig` and keep line endings consistent.
- Python uses 4 spaces; all other files default to 2 spaces.

## Branching and commits
- Use `feat/`, `fix/`, or `chore/` prefixes.
- Follow Conventional Commits for messages.

## Documentation
- Update relevant docs when behavior or configuration changes.
- Keep runbooks current with deployment steps.
