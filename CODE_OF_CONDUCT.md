# Code Of Conduct

VeggieAI is an academic project. The working standard is simple: be respectful, be honest about evidence, and keep feedback focused on improving the system.

## Expected Behavior

- Use welcoming and professional language in issues, pull requests, reviews, and documentation.
- Credit external tools, datasets, libraries, generated assets, and references honestly.
- Raise risks early, especially security, privacy, data, or deployment concerns.
- Review code and documentation by discussing behavior, maintainability, and evidence.
- Respect Singapore Polytechnic academic integrity expectations and module requirements.

## Unacceptable Behavior

- Harassment, insults, discriminatory remarks, or personal attacks.
- Publishing secrets, credentials, private data, or student records.
- Misrepresenting test results, model performance, authorship, or deployment status.
- Adding hidden behavior that bypasses authentication, tests, security controls, or auditability.
- Copying third-party work without permission, attribution, or license compatibility.

## Reporting

For coursework matters, contact the repository owner or the lecturer through the appropriate Singapore Polytechnic channel. Security concerns should also follow `SECURITY.md`.

## Enforcement

The owner may remove inappropriate content, revert unsafe changes, or block contributions that violate this code. Academic concerns are handled according to Singapore Polytechnic and module policies.
