# Documentation

This folder is the documentation hub for the VeggieAI MLOps Platform.

## Contents

- `architecture.md`: service boundaries, data flow, and inference routing.
- `api-contract.md`: endpoint and response contract.
- `cicd.md`: CI/CD gates, required variables, artifacts, and deployment flow.
- `development.md`: local development workflow and code quality checks.
- `environment.md`: environment variable reference.
- `mlops.md`: model registry, promotion, smoke checks, and rollback.
- `model-governance.md`: model-card style notes and approval checklist.
- `release.md`: release and tagging process.
- `security.md`: application and pipeline security controls.
- `standards.md`: coding, testing, and documentation standards.
- `testing.md`: pytest strategy and marker usage.
- `runbooks/`: operational runbooks.
- `adr/`: architecture decision records.
- `evidence/`: screenshots, deployment proof, reports, and assignment evidence.
- `wireframes/`: UI wireframes and source mappings.
